填入 DeepSeek 的 API key，瓶子漂回来时会带上一段人鱼写的回音。 key 只存在这台手机上，不会上传到任何地方。留空则用内置的回音。
瓶子漂回来的时候提醒你一下。需要先把「潮汐」添加到主屏幕， 并且从主屏幕图标打开（iOS 16.4 以上）。App 被系统完全清掉时不会响。
呼吸和下潜的浪声走的是媒体音量，侧边静音键关着也能响。 听不到就点下面试一下，然后用音量键调大。
