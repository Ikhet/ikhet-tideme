# 潮汐 · 装到 iPhone 主屏幕

一个不需要开发者账号的 PWA。本质是网页，装完之后有自己的图标、全屏、能离线用，不会 7 天过期。

---

## 一、先传到网上（三分钟，不用注册也能先试）

需要 **HTTPS** 才能装成 App，所以不能直接打开本地文件。挑一个：

### 方案 A · Netlify Drop（最省事，推荐第一次用）

1. 浏览器打开 <https://app.netlify.com/drop>
2. 把整个 `tide` **文件夹**拖进页面（不是拖 zip，是拖文件夹）
3. 几秒后拿到一个 `https://xxxx.netlify.app` 的地址

改代码之后重新拖一次就更新了。想固定域名就注册个免费账号，在站点设置里改 site name。

### 方案 B · Cloudflare Pages

登录 → Workers & Pages → Create → Pages → Upload assets → 拖文件夹。免费、国内访问相对稳。

### 方案 C · Vercel

<https://vercel.com/new> → 需要连 GitHub，适合以后要持续改的时候。

---

## 二、装到主屏幕

1. **用 Safari** 打开上一步的网址（一定是 Safari，不是微信里点开的）
2. 点底部中间的 **分享** 按钮 ⬆️
3. 往下滑，选 **「添加到主屏幕」**
4. 名字留「潮汐」，点添加

主屏幕上会出现一个深蓝色海面 + 月亮的图标。点进去是全屏的，看不到 Safari 的地址栏。

> 装完之后断网也能打开（service worker 缓存了）。

## 三、改代码

所有东西都在 `index.html` 一个文件里，改完重新拖一次就行。几个常改的地方：

| 想改什么 | 搜索这个关键词 |
|---|---|
| 水位对应的短句 | `const PHRASES` |
| 每日一句肯定语 | `const AFFIRMATIONS` |
| 下潜时浮出来的句子 | `const DIVE_LINES` |
| 月相对应的水系魔法行为 | `const MOON_RITUAL` |
| 呼吸节律 | `const PATTERNS` |
| 漂流瓶多少分钟漂回 | `const RETURN_MIN` |
| 人鱼的性格与说话方式 | `const MERMAID_SYSTEM` |
| 没填 key 时的备用回音 | `const MERMAID_FALLBACK` |
| 新手引导的文案 | `const OB_STEPS` |
| 海的配色 | `const water = cx.createLinearGradient` |
| 下潜最深多少米 | 搜 `k*200` |

**测试小技巧**：想立刻看到漂流瓶漂回来的效果，把 `RETURN_MIN` 改成 `[0, 0.1]`，试完再改回 `[3, 8]`。想重看一遍新手引导，在设置里清掉 Safari 数据，或者搜 `onboarded` 把那行判断临时注掉。

## 四、漂流瓶的回音

瓶子漂回来时会带一段"海里那个人"写的话。

**不填 key**：用内置的十条回音，随机选，离线也有。

**填 key**：我的海 → 设置 → 填入 DeepSeek 的 API key（在 <https://platform.deepseek.com> 申请），点保存。key 只存在你这台手机的本地存储里，不上传任何地方；分享给别人时对方填自己的。

回音是在**投瓶的那一刻**就生成好存起来的，不是等漂回来才现算——所以中途关掉 App 也不影响。

> ⚠️ 有个不确定的地方：浏览器直接调 DeepSeek 接口可能被跨域策略（CORS）拦住。设置里有个「测试连接」按钮，点一下就知道通不通。如果提示连不上，把那句话发给 Claude，加一个十几行的中转接口就能解决（Netlify / Vercel 都支持，免费）。拦住了也不影响用，只是回音会退回到内置的那十条。

## 五、瓶子漂回的提醒

我的海 → 设置 → 「打开瓶子漂回的提醒」。到点会弹一条系统通知，主屏幕图标上也会出现小红点。

**必须满足的条件**（iOS 的限制，不是代码的问题）：

1. 已经「添加到主屏幕」，并且**从主屏幕的那个图标打开**——在 Safari 标签页里打开的不算
2. iOS 16.4 或更新
3. App 还在后台。你切到别的 App、锁屏都没关系；但如果被你上滑关掉了、或者被系统为了省内存清掉了，那条通知就不会响

第 3 条是网页 App 绕不过去的坎。真正"关掉也能收到"的推送需要一台一直在线的推送服务器（Web Push + VAPID），那是另一个量级的工程。考虑到瓶子只漂 3–8 分钟，你多半还没退出，现在这样够用。

漏掉了也不会丢：下次打开 App，瓶子就在瓶子那页等着。

## 六、数据存在哪

全部存在手机本地（`localStorage`），不上传任何服务器，Claude 也读不到。

代价是：**删掉 App 或者清理 Safari 数据，记录就没了**。以后想加导出功能，或者换成同步到云端，都可以再做。
